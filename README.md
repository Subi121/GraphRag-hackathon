# GraphRAG Comparison Dashboard

This project compares:
- LLM Only
- Basic RAG
- GraphRAG

## Features
- Side-by-side pipeline comparison
- Token estimation
- Latency tracking
- Cost estimation
- Graph-based reasoning

## Tech Stack
- Python
- Streamlit
- OpenRouter API
- TigerGraph GraphRAG
